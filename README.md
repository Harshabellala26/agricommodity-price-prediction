#🌾Agri Commodity Price Prediction

An AI-powered web application that predicts the future prices of major agricultural commodities in India using Machine Learning and Time Series forecasting techniques. The system analyzes historical market prices and trends to provide both short-term and long-term price predictions, helping farmers, traders, and consumers make informed decisions.

🚀 Key Features
📈 Predicts prices of multiple agricultural commodities.
🤖 Uses Random Forest Regression for short-term forecasting.
📅 Supports long-term trend prediction using LSTM/ARIMA models.
📊 Interactive data visualization for historical and predicted prices.
🌐 Flask-based web interface for easy access and usability.
🧹 Automated data collection, preprocessing, and feature engineering.
🛠️ Tech Stack
Backend: Python, Flask
Machine Learning: Scikit-learn, TensorFlow/Keras, Statsmodels
Data Processing: NumPy, Pandas
Visualization: Matplotlib
Frontend: HTML, CSS, JavaScript
Dataset: Historical agricultural commodity price data from Indian government market sources
🎯 Objective

To empower stakeholders in the agricultural sector with data-driven price forecasts, enabling better planning, reducing uncertainty, and supporting smarter decision-making in commodity trading and farming.
